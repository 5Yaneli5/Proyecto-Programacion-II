PROYECTO PROGRAMACIÓN II

AVANCE I

Hice este proyecto pensándolo como una tienda de libros digital y en una de esas lo más importante son los libros y esa es la clase para este avance. Esta clase llamada “Libro” representa el producto que vendería esta librería digital y para mí tiene sentido ponerla como clase porque le puedo atribuir varios métodos y atributos pero principalmente porque no hay un solo tipo de libro pero sí que comparten características (atributos) como género, autor, precio, stock, es decir cada libro se convierte en una entidad independiente con características comunes, lo que lo hace perfecto para aplicar la programación orientada a objetos.
