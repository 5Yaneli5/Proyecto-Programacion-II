PROYECTO FINAL DE PROGRAMACIÓN II

Hice un sistema en Python que aplica Programación Orientada a Objetos para gestionar una librería. Permite administrar libros físicos y digitales (Libro y LibroDigital), manejar precios protegidos mediante encapsulamiento, controlar el stock y registrar valoraciones de clientes mediante composición con una clase auxiliar de reseñas (Reseña). Además, demuestra polimorfismo al mostrar la información adaptada según el tipo de libro y está estructurado en módulos (modelos.py y main.py).
